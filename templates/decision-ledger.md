# Decision Ledger: <title>

Only the author writes rulings here. Agents read this file and follow it.

**How to fill it in.** Under each question, replace `Ruling: OPEN` with your
decision, then the date and your initials. A ruling can be one line. To leave
a question for later, write "deferred to <stage>" with a reason. When every
question reads something other than OPEN, mark Gate 3 in `gates.md`.

Each ruling has an id so drafts can link to it; never reuse or renumber one.
Ids are `###` headings, written exactly as below (the check script reads them):
- `X1`, `X2`, ...: questions across units.
- `U01-D1`, `U01-D2`, ...: questions for one unit (unit id, D, number).
- `S1`, `S2`, ...: questions raised after Gate 3 (from drafting or later).
