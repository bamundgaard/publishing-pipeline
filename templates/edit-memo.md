# Edit memo template (the developmental editor writes these in 06-dev-edit/)

## Unit memo: 06-dev-edit/<unit-id>.memo.md (round 2: <unit-id>.memo.v2.md)

```markdown
# Edit memo: <unit-id> · <reference or headword>

Draft read: 05-drafts/<unit-id>.md (or .v2.md) · Round: 1 of 2
Verdict: Ready for review / Revise / Needs the author
Scores (1 to 5, 4 = as good as the marked-up sample): Question <n> · Argument <n> · Coverage <n> · Reader fit <n> · Voice <n>

## Summary
Two to four sentences: does the unit do its job, and the single most important change.

## Keep
- <what works and should stay>

## Must fix (for the drafter)
MF1. Where: <section, "first few words..."> · Problem: <...> · Why: <plan / charter / ledger id / style-sheet rule> · Aim: <what the revision should achieve>

## Should fix (for the drafter)
SF1. Where: ... · Problem: ... · Why: ... · Aim: ...

## For the author
A1. <decision needed> · Options: <as the dossier or charter gives them> · Blocks review: yes/no

## Round check (round 2 only)
- memo MF1: done / partly / not done

## Passed to verification
- <possible fact error and where>

## Missing inputs
- <style sheet, sample unit, calibration notes>
```
